# 第三轮协议：按义务搜索完整证据

## 假设与边界

第二轮发现，预先为每个节点缓存 OR 替代证明会耗尽资源，丢失唯一独立见证。
本轮研究原型将查询转换成两侧证明义务：每侧完成一个不同顶层评估的全部 AND 来源，
展开时立即排除另一侧已使用的 capture 或中间节点；允许同侧共享，允许 OR 回溯。
循环必须按路径拒绝，未完成的义务不能获得支持。count 与 confidence 分别最大化。

该设计是 MindBridge 证据语义下的约束搜索实验，不声称发明回溯搜索，也不声称
具有神经科学上的等价性。原型只放在忽略的 `autoresearch/` 目录，不改变产品默认行为。

## 固定对照

- A：现有 `independent_support`，64 条缓存证明、4,096 步。
- B：按义务搜索，4,096 个搜索状态，不缓存所有替代证明。
- C：B 去掉中途跨侧排斥，只在完整证明产生后检查不相交。
- D：A 使用 1,024 条证明、200,000 步，仅作资源诊断。
- 独立 oracle：小图上穷举全部有限无环证明，不复用候选的实现。

两个算法的“步”对应不同操作，不能仅据相同步数声称算力相同。同时记录实际时间、
搜索截断和独立内存测量；编译实验固定 item/字符预算。任何超预算对照都单独标注。

## 样本与失败条件

复用第二轮冻结的 504 图容量矩阵，属于已知回归集。新增独立审查者固定的反例、
随机图种子作为独立实现检查，覆盖联合证明、同源 capture、共享中间摘要、循环、
缺失来源、零置信度、弱而唯一的证明和撤销。样本/源文件哈希在调用前写入 manifest。

公开 SDK 使用原有固定形成提案和常量嵌入，对比相同输入、独立目录中的 A/B 路径。
B 仅在研究进程替换纯支持函数，恢复后不影响其他运行。不调用回答模型，不改变
提案、检索、可见性阈值或产品预算。结果仅代表声明证据图，不代表自然感知质量。

编译研究将完整引证并集与选定的完整证明比较。保留必要 AND 来源与达到要求的独立
支持，不得通过只留结论、只留部分引证或降低所需 confidence 获益。原型交付可验证
的证明证书，不把离线证书选择声称为已经集成的 SDK Context Compiler 功能。

以下任一结果阻止候选进入产品：虚增支持、超出 oracle 的分数、不完整证书、超过
编译预算，或没有报告的能力退化。有限预算漏学、名称敏感性、耗时与内存均必须报告。
若初版失败，保留初版文件与结果，修订写入新版本，不能覆盖失败记录。

## 接受标准

首先要求独立 oracle 与证书核验零不安全结果；其次才比较合法学习、编译交付和成本。
通过合成实验只能保留为下一阶段候选，不能据此宣布泛化突破。真实模型的历史身份
见证恢复属于另一项机制，本轮不把这项尚未实现的能力计入收益。

## 对抗审查触发的版本修订

v1 的预算外证明对物化与 Python 递归溢出被反例否定后，v2 改用惰性配对、显式栈和
共享的证书前缀。v2 在只有 24 个节点的共享 AND 图上仍耗尽 4,096 步，因此 v3 将
每侧证明表示成 DAG：一个节点选择一个完整 clause，同侧复用子证明，新边必须通过
无环检查。v3 的证书由每个节点及其选定的全部来源组成，不再重复输出证明树。

三版分别保存源码、调用前 manifest 和全套结果，不覆盖前版失败。v3 重跑相同容量、
SDK、资源和独立 oracle 输入；已由前版揭示的反例属于回归检查，不称为新的盲测。

交付审查另外要求联合核算 count 与 confidence 的证书：两组证书各自满足预算，
不代表它们的并集满足预算。离线选择器必须在实际输出并集上同时满足两项义务，
否则拒绝交付。这项审查保持所有初始预算和能力要求不变。
