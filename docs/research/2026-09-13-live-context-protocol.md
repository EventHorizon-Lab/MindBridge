# 第四轮协议：真实形成与实际 Context 交付

## 问题与固定原则

检验第三轮按义务搜索证明 DAG 能否改善真实模型形成的记忆，以及公开 `Memory.compile()`
实际返回的 ContextBundle。形成正确性与交付正确性分别评价，不调用回答模型或 LLM
judge，不改变形成提示、评分阈值或既有 Context 引证契约。

现有 `MemoryContext.evidence_ids` 是权威来源并集，现有 Context 要求其完整递归闭包。
缩减 `EvidenceClosure.members` 而保留这些来源会产生未交付引证；改写权威语义或在
预算外附加证明，也不能被计作兼容现有 API 的改进。

## 真实形成实验

固定四组、每组六条合成自然文本：重复明确陈述、不同人物的同类陈述、单一人物后
的跨次代词、两个人物后的歧义代词。调用已配置的 qwen3.8-27b，temperature=0、
固定 seed、最多 1,500 输出 token、25 秒请求超时，不开启客户端自动重试。
正式上限为 24 次 FORM、72 次 HTTP，HTTP 包括已有适配器的结构验证重试。

每条输入逐次通过公开 SDK 形成，保存真实提案与失败。随后在新的独立目录中通过
ReplayFormer 重放完全相同的 typed proposals：A 使用当前 independent-v1 算法，
B 在研究进程替换为 v3。若引用需要重绑，仅按输入位置映射真实源 ID，不更改内容。
记录完整请求体、响应和用量，但不记录请求头、URL、凭据或配置副本。

形成评分检查输出正文和类型字段，EVENT 的 subject 为空不是自动失败；具名绑定
同时需要相应姓名/事实与必要来源。模型/结构验证失败不能当作安全拒绝通过。歧义
例不允许任意实名绑定。无条件保留全部预定输入的结果，不择优重试。

v3 不改变 former 的输入，因此相同提案重放主要隔离记忆投影效果；生成模型本身
是否更会形成记忆，不能从投影或交付率变化推断。

## 实际编译与兼容性消融

- Full：原 `Compilation._evidence_closures` 和原 ContextBundle 选择/渲染。
- Trim：研究进程按 v3 证明缩减闭包成员，保留全部权威 SearchHit/MemoryContext。
  这是待证伪候选，不能仅按目标是否出现在 bundle 中判为成功。
- Guard：只有选定成员仍满足现有递归引证契约才接受缩减，否则使用原闭包。

三种路径都调用公开 `Memory.compile()`，保留原排序、置信度过滤、冲突、consent 和
实际 bundle 预算计算，不把离线选择器输出称作 SDK 交付。存在 RetrievalScope 的
请求沿用 Full，避免以当前 clause 读法误用 known_at 之后的边。

除真实形成记录外，固定结构控制包括独立 OR 来源、联合 AND 来源、共享来源及
删除。每次调用保存 `render()`、`compact()`、`document()`，比较目标是否交付、
必要递归引证是否齐全、冲突与拒绝是否保留、items/媒体与 chars 是否满足公开契约。

`max_chars` 按产品定义约束有价的 Context 内容，不是完整 JSON 或 UTF-8 字节上限；
诊断块在公开契约中另计。实验同时报告完整渲染字符、UTF-8 字节和传输 JSON 大小，
不能悄悄混用这些指标。

## 接受与停止

缺失必要引证、未经授权改写权威字段、scope 泄漏或把失败记作成功，都否定候选。
若只能提高表面交付率，应明确报告不成立，并指出需要验证的新交付协议，而不是
降低原有契约。真实模型规模、合成文本分布和常量嵌入的局限必须随结论一起报告。
源码、案例、调用前 manifest、失败及修订位于忽略目录
`autoresearch/corroboration-context-live-260913/`，产品文件不改。

## 主实验之后的兼容性诊断

主实验常量嵌入将结构控制中的原始记录排在目标之前，小预算在目标出现前已满，
因此没有暴露缩减闭包的公共引证问题。保留全部主结果后，另固定同样五个结构与
预算，用通用词项哈希嵌入建立新库；不对目标或案例名称特判，三种模式保持相同
索引与检索。这是事后组件诊断，不是盲测或自然检索质量验证。

独立审查另构造三个 OR 来源、其中一个很长的公开 SDK 反例。长原文因字符预算
被跳过，目标与两个短来源可以进入缩减版，从而直接验证公共引证是否完整。
无故障注入版本与模拟来源级 consent 拒绝的版本分开保存；后者不代表现有 consent
政策存在漏洞。两种诊断都不改变主实验的评分、数据或结果。
