# ATM raw main 与 Mem-Gallery：最佳已验证配置与能力突破方向

截至 2026-10-29，本轮完整实测的 ATM 原始输入加英国外部 OSM 条件 QS 为
**0.6403978**；不附加外部地图的 raw baseline 为 **0.5949725**，Mem-Gallery
F1 为 **0.7945851**。当前推荐以原始记忆、原生多模态检索、有界扩展和远端
非 thinking reader 为基础，分别设置两任务的证据预算。它们还不是已认证 SOTA。
完整实现、运行与失败记录见[能力修复记录](2026-10-28-atm-gallery-capability-run.md)。

两个实际可连接地址为 `http://172.21.80.127:8001/v1` 与
`http://172.21.80.127:8000/v1`。用户原先提供的 HTTPS VLM 地址没有连通。
这些服务使用模型别名，服务 fingerprint 可以记录，但没有据此固定权重 commit 或精度。
Judge 使用独立的 gpt-5-mini 服务，密钥只从进程环境读取。

WeMM 保持完整 4096 维，不做 MRL 截断或索引量化。其[官方模型说明](https://huggingface.co/tencent/WeMM-Embedding-9B)
要求使用专用 embedding chat template，取 `<embedding>` 位置的表征并做 L2 归一化；
不能仅因接口兼容 OpenAI 就改用普通聊天模板或平均池化。MindBridge 当前用 `messages`
承载原生媒体，没有额外套用 E5、Qwen text embedding 等其他模型的检索前缀。
已检查的服务端文本 tokenization 末尾含专用 token，但这还不能独立证明远端权重、
池化实现和视频采样全部等同官方实现；本地模型卡的设置不能冒充服务端启动参数。

这里的 32000/64000 是证据正文的字符预算，**不是** provider token 上限；它也不包含
全部字段、系统提示或视觉 tokens。`recall_limit: 12` 是初始锚点数，后续集合与
改写可提供更多记录。图片按原件身份去重并验证 SHA，仍须检查最终实际交付的媒体。
参数越大并不自动得到更高质量：Gallery 的宽上下文候选没有取代 32k 配置。
`recall_rounds: 2` 是上限，只有首轮拒答时才再尝试，并非每题都运行两轮推理。
跨轮额外语义搜索最多两次，重复查询复用结果；提高轮数不能自动扩大这个上限。

可复用的完整产品配置位于本地 `.benchmarks/sota-20261028/eval_review/` 下的
`best-verified-atm-raw-main.yaml` 和 `best-verified-mem-gallery.yaml`，已从实际全量
运行还原并显式写入 reader temperature 0.7、seed 0；不含 judge 配置或密钥。
`README-best-verified-baselines.md` 与 `best-verified-baselines-bindings.json` 记录
公共 `ask(limit=12)`、strict policy、源码、语料与评分绑定。两份配置均在对应冻结
源码和当前配置解析器中零客户端、零网络通过验证。原始实验 YAML 没有显式固定
reader 温度，仍保留原件。完整重现还需对应冻结源码、原始输入、自产描述库与
评分协议；在新源码上只复制 YAML 不构成旧成绩的逐字复现。

若采用下文说明的英国外部 OSM 条件，最高已验证完整配置另存为
`best-verified-atm-with-gb-osm.yaml`；同名 Markdown 与 `-bindings.json` 保留
完整 1013 题、两段 producer、原始预测字节及官方评分绑定。原无地图快照不覆盖。

## 为什么暂不打开更多记忆功能

当前 reader 已收到相当多必要来源。ATM v6 中，272 个错误开放题有 208 个已经收到
全部标注证据；Gallery 的整榜 R@10 为 0.90460。增加候选池不能单独解决这些错误，
仍需要辨认图中实体、绑定活动、正确处理时间与否定，并回答完整的关系。

普通 formation 的完整 Home Repair 语料产生 418 条派生事实，内容审查发现 407 条
有源支持，但部分 STATE 属性槽过粗：可共存拥有物互相截断有效期，不同症状互相替代。
68 题 F1 从 0.68603 到 0.71802 的涨分中，约 92% 净增分来自两题拒答格式变化。
这不足以证明长期记忆能力改善，故不启用为最佳配置。

更具体的语义提示修正了拥有物误截期，但本地 Q4 与远端服务的完整源文本测试仍有
代词解析、时间粒度或状态遗漏。远端三个同属性更新正确；“动作完成”的 EVENT 却不
一定刷新旧“尚未完成”的 STATE。应改进 proposal 对具体实体、单值属性和更新含义的
表达，不能删除置信度与权威保护来强迫新值获胜。

ATM 的 Number 类也包含日期、时间和金额，不能将剩余错误统一解释为集合计数不足。
前十个残余错误的源审中，一个明确模型错误是把海报里的活动时间答成“看到广告”的
时间，尽管正确原图、记录发生时间和 EXIF 拍摄时间都已交付；这需要区分拍摄、
文中事件和用户经历的时间角色。另有题目要求 2023-11-03 的“明天”，标注邮件
却明确活动在周一 11 月 6 日，答案取邮件的 140 人上限。这先列为题目与标注证据
冲突，不改官方分数，也不为命中该数字而教模型忽略题内日期。

这与[Zep 的时态图方法](https://arxiv.org/html/2501.13956v1)所强调的有效时间和事实
失效问题有关，但图结构本身不会保证正确事实形成。
[RAW-RAG](https://arxiv.org/html/2610.30755v1)保留原始推理上下文的思路，更适合作为
当前可信原件路线的依据；不能把它没有报告的 Gallery 分数当作本任务目标。

4090 上的固定 27B Q4 runtime 可以降低部分形成和规划成本，但目前未保住最终质量。
同一形成库中，本地 planner 将中位规划时间从 51.24 秒降至 1.49 秒，68 题 F1 却从
0.71802 降至 0.70529。当前以最高成绩为目标，reader 与 planner 仍采用远端服务。

## 已经具备真实增益的突破方向

此前验证了照片 GPS 的离线几何证据。用户于 2026-10-29 明确无需围绕 GPS
继续寻找服务，后续不新增地图服务、数据或分支；已有结果独立保留，已启动的
空间索引全量评测继续收尾。能力主线转向原始文本与图像的对象、属性、行动及
时间绑定。英国固定快照的固定 reader 证据、32k 配置完整
342 题配对中，QS 从
0.43952 到 0.51540，40 胜、13 负，逐例确认有具体地点恢复。这不是全榜分数：
选集由官方线索与地图覆盖交集定义，54 题实际没有收到可增补地图的目标图。
地图也会误导 reader 把附近要素当成照片对象，不能直接返回最近 POI。

随后，英国地图分支在全部 1013 题的完整 QS 为 **0.6403978439**，相比无地图 v6
的 0.5949725004 提高 **4.54253 个百分点**，80 胜、31 负、902 平，生成和评分
错误均为零。Number 360 题从 0.7500000 到 0.7722222，List 139 题从
0.6525694 到 0.6958490，Open 514 题从 0.4708171 到 0.5330739。
全部标注来源与原件覆盖仅从 869 到 871 题，尚不支持把涨分解释为大幅召回改善。
7 题逐字相同预测出现 judge 翻转，净 score mass 为 -1，单独保留。
这次完整结果由原 59 题与完成顺序定义的剩余 954 题严格合成，没有重答、挑题或
重评分；不伪装成单次不间断运行。虽然配置新增项是地图，v12 也包含其他产品
实现差异，不能把全部差额称为纯地图消融。此条件含外部世界知识，不能作为
无外部知识 raw 分数。
独立审查全部不同预测的分数变化后，42 个不同答开放题胜例中有 25 例确实恢复或
纠正了关联原件上获准候选的地名／更细区域。National Portrait Gallery 等案例的
原始 ranking、实际记录及图片顺序相同；另有 source-kind、拒答及时间成分变化。
因此有实际内容增益，也仍不能把全差额视为地图的纯因果效果。

产品已实现默认关闭的 `OfflineGazetteer`：只查本地固定快照，用真实几何距离与包含
关系提供最多 500m、8 个候选，整请求新增内容最多 16000 chars。来源、快照日期、
许可和索引摘要保留；这一回答时适配器不写回记忆，不生成“已确认的照片身份”。
[Geofabrik 官方说明](https://download.geofabrik.de/technical.html)区分真实提取多边形
与行政边界，不能用近邻城市名称冒充覆盖证明。

英国完整 1013 题验证已完成。此前按源分布预选的埃及、路易斯安那和上海已构建完整
地区索引，与英国合并后共 4906320 个要素。旧索引的四区域全榜分支已启动，
2026-10-29 00:25:25 UTC 为优先新空间索引而中断；保留已完成产物，未按前缀
质量决定停止，也不以其未完成结果评定方案。地图增加了外部世界知识，须与
无地图的 raw 成绩分开披露，不能冒称仅由原件推理得到。

此前还检查了索引阶段的缺口：回答时才追加地图，不能召回此前没有检索到的照片。
对全部 3759 张源照片做不读取 QA 的离线检查，2694 张有空间候选，其中 2546 张的
旧自产描述没有任何候选名称的精确词匹配。这只说明缺少可检索的地名字符串，
不等于这些地点就是图中对象。正在核查通过公共 `add_many` 在独立目录中构建新的
描述索引：保留旧视觉描述和原件，将捕获坐标附近的地图候选单独标明来源、距离及
覆盖关系，不把它们写成已确认的视觉事实。这个方案尚未运行完整评估。

向量复用方案已放弃：源顺序前两条邮件和首张图的三次逻辑输入，在一次真实服务
请求中与历史向量的余弦为 0.999813、0.999770、0.999933，未达到事先固定的
0.99999 门槛。它们很接近，这不能证明服务权重变更；也没有事后放宽阈值。
新候选将保留旧 caption、重新计算全部向量，不能再用旧方案的 8189 个 cache miss
估算实际工作量。全部 11034 条源数据的严格零网络检查和 7 项 CPU 测试已通过，
固定 10 条源输入的真实公共 SDK 摄取已通过：4 次实际 embedding 请求、27 个全新
向量、21034 input tokens，零 VLM caption 请求，SQLite 完整性及索引同步正常。
全部 11034 条源记忆的新库随后完整构建并通过终审核心检查：21453 个新向量、
2768 次实际 embedding 请求、14995738 input tokens，零新 caption 调用，全部
原件、时间、身份和预期缺口均保持。完整 1013 题入口零网络预检通过；第一次
启动因评分器过早建立输出目录而在模型调用前失败，零预测、零评分调用。保留
失败后已用新目录重新启动，实际初始化和独立复制均通过，随后才启动评分器；
尚无新成绩。全部 embedding 也已重算，整条管线的比较不能被描述为只改变地图
文本的消融。

[GeoCLIP 原始实现](https://github.com/VicenteVivan/geo-clip)将图像与 GPS 对齐，
[OSMLoc](https://arxiv.org/html/2411.08665v1)进一步结合视觉语义与地图几何；两者都
不能证明“最近要素就是照片中的对象”。这里保留真实 EXIF 坐标，不另用模型预测
坐标覆盖原始观测；空间候选还需要原图核验。这是对这些方法适用边界的判断。

Gallery 的另一条路线是提高 reader 实际感知分辨率。当前每图 1MP；全量输入资产
统计发现，806 题在 4MP 下会改变传输预算，其中 749 题的理论总像素仍不超过
24 MiPixels，覆盖全部 20 个主题。已完成的配对保留相同证据、原件和问句，仅改变图像
传输预算；像素计算不等于服务端视觉 token 或正确识别，必须验证实际输入和答案。
同一原图的真实 `/tokenize` 检查已确认 1MP 到 4MP 将视觉占位 tokens 从 1014
提高到 4056，其余 316 个 tokens 的序列完全相同。37 题、20 主题的固定证据配对中，
F1 从 0.7566373 降至 0.7089841，1 胜、7 负、29 平，
双方零错误。4MP 最大实际输入 29299 tokens，未触及上下文上限；唯一微小增分
只改写了措辞。因此维持 1MP，不运行全量自适应 4MP 候选。172 题的语义查询拆分
也从 0.7824262 降至 0.7560281，虽实际来源覆盖略升，仍未晋级。这两项结果支持
将下一步聚焦于证据的实际辨认和绑定，而非单独增加分辨率或召回覆盖。

下一项私有原型是由本地 4090 上的模型查看 1MP 全局图，提出最多两个区域，再从
原件裁剪细节交给远端 reader。它受 [V*](https://openaccess.thecvf.com/content/CVPR2024/html/Wu_V_Guided_Visual_Search_as_a_Core_Mechanism_in_Multimodal_CVPR_2024_paper.html)
和 [ZoomEye](https://aclanthology.org/2025.emnlp-main.335/) 的局部检视思路启发，
尚未实现这些论文的完整算法，也未证明本任务增益。原始问句、全部已选证据和
原生图片必须保留；裁剪标为同一来源的派生视图，不能增加照片或事件计数。
8 个独立合成定位任务已真实运行：8 次本地请求均正常结束，严格门槛通过 6/8。
另两例的框偏大，目标覆盖率虽均为 1，但 IoU 低于预定 0.5；两个负例均正确返回
空框。保留失败，不降低门槛。随后增加一次通用区域重定位，同样 8 个任务和门槛
通过 8/8，共 15 次本地请求；此前两例 IoU 提高到 0.950095、0.936382。
8 个全局请求字节及响应与前版相同，改善来自新增局部步骤。这只验证基本机制，
不能替代 Gallery 问答质量。真实 37 题候选已启动，保留全部原始证据并追加同源
局部视图，实际调用分别经过本地容量上界和远端 token 准入。两题超过当前 13 张
不同图像的限制，保留在原选集中并完整回退原始请求。完整结果随后为
0.7566373 到 0.7545911，1 胜、3 负、33 平，双方零错误；仅两题实际追加裁剪且
得分均未变，所有分数变化均来自原 prepared 请求未变的题目。因此不晋级纯裁剪。
下一项原型将同次本地检视输出限定为绑定原图的少量可见文字、外观和空间关系，
不输入旧 caption、记录正文或时间，也不形成用户拥有、活动或事件事实。21 项
CPU/HTTPMock 检查与两臂零网络预检通过后，真实固定 37 题已完成：F1 从
0.7566373 到 0.7209743，1 胜、8 负、28 平，双方零错误，不晋级。
18 题实际追加提示，其中 1 胜、3 负、14 平；其余题原 prepared 请求未变，仍有
5 次得分下降，须与增补效果分开。唯一增分只是删去正确答案的同义词，没有新增
视觉辨认事实。18 题中 17 题只描述前四个来源，另一题描述全部两个来源，尚未
观察到主动选择尾部关键图像的能力。此处语义限制是模型提示要求，结构校验通过
不证明实际观察正确。独立审查全部 70 条提示与原图，未读问句、参考、预测或评分：
44 条主要内容有图像支持，18 条含不能确证的子断言，8 条含明确错误子断言，
包括计数、OCR 和外观误读。这是每条提示按最弱子断言分类，不是感知 precision，
也不能据此逐条解释问答失分。每题最多
4 个来源的提示正文另有 6000 字符限额，在原 32k record body 之外明确收费，全部
附录和裁剪仍共同经过远端实际 token 准入；原图与原始证据不被驱逐。

同时准备了一项尚未接入评测的读取时证据对齐核心，针对对象、具体属性、说话角色、
否定／建议／完成语气及时间角色混淆。它只读当前实际已交付记录，最多输出六行，
每行原话必须在指定记录中唯一精确出现；最多一个前项锚也需同样核验，实体 mention
须来自这两段原话之一。主机保留原始时钟并核对 prepared 映射，不自动合并属性、
