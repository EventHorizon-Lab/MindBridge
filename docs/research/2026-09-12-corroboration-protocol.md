# 原始证据约束的巩固实验协议

## 问题与假设

基线固定为 `599ae4b`。本轮不改回答提示、拒答策略、检索窗口、评分器或模型。
当前 `_evidence_summary` 对单源评估按 capture group 合并，却把全部联合评估压成一个
最大值。来自两个不重叠情景的联合评估不能积累为可见的 inferred trait；多根摘要又会
退化为一个新的 group ID，可能掩盖与其他摘要共享的根证据。

假设：将巩固支持表示为 AND/OR 证据证明，并要求两份证明的原始 capture 和中间推导
互不重叠，能同时恢复独立情景的学习和抑制重复摘要的自我佐证。
这是 MindBridge 证据子句、可撤销巩固与身份可见性契约上的算法实验，尚非原创性或
跨模型、跨真实模态性能的证明。

## 候选机制

每个 clause 是 AND，每条记忆的 clauses 是 OR。原始观察保留 host 提供的 `source_id`
作为 capture group，缺省使用记录 ID。中间派生记忆也进入证明 footprint，避免同一个
摘要通过不同路径自我佐证。OR 分支必须分别保留，不能把所有祖先做 union；增加一个
替代支持不能在未触及资源上限时破坏已有的独立证明。

候选只寻找最多两份不相交证明，因为现有可见性门槛就是两组。独立支持数饱和于二；
置信度为有效单证明和不相交证明对的最大 noisy-OR 值。它是保守的策略分数，不是
统计独立性已被验证的概率。每条证明的分数受沿途最弱证据置信度限制。
同一个顶层 clause 的不同证明不能算两次评估。

证明枚举和 SQLite 祖先读取均有明确上限；循环、缺失和截断不能制造支持。
有限证明集合提供可验证下界，不能被报告为完整证据容量。
证据变化必须刷新整个依赖闭包，不能只依赖旧的单个 group ID 是否变化。

以 `MemoryConfig.independent_evidence` 显式选择候选，默认关闭。策略作为 store metadata
固定，已有 legacy 数据不能静默切换；不同实验臂使用独立临时目录。无 schema 改版、
无新依赖。证明算法本身不请求模型；身份名称变化仍需更新已有语音的嵌入。
现有 AND 撤销、历史版本、SQLite/outbox 顺序继续成立。

## 预先固定的比较

| 臂 | 机制 | 用途 |
| --- | --- | --- |
| A | 当前 singleton noisy-OR + joint max | 产品基线 |
| B | 原始证据约束的双证明支持 | 候选 |
| C | 将 clause ID 当独立来源 | 取消来源约束，检验虚假增益 |
| D | 把 OR 祖先做 union | 取消替代证明，检验过度保守 |

A/B 必须通过公开 SDK 写入、consolidate/apply、get/search/compile、rollback/delete。
C/D 是离线机制消融，必须明确标注，不能冒充产品运行。
固定所有观察和评估提案，不调用 answerer；同一 case 的各臂使用相同输入、条数和编译预算。
主要指标是合法学习率、错误佐证率、撤销后残留率、证据闭包正确性；同时记录 latency、
模型调用数、实际预算和资源。正例与负例分开报告，禁止靠只提高可见率宣布成功。

开发集先覆盖独立联合情景、共享 capture、共享多根摘要、OR 替代、嵌套推导。
保留集使用独立随机种子、不同图结构和更深层级；所有输入与预期必须先固定再看结果。
重命名、输入排列、重复评估和重开数据库作为变形测试。以独立 case 为统计单位报告
配对差异；模板随机变体不能被当成自然分布独立样本。

接受条件：开发和保留结构中修复 joint under-learning；所有共享来源与撤销负例零新增
错误；默认 A 的现有测试无回归。候选若未通过则修订或撤回。即使全部通过，也仅支持
有限图结构上的机制正确性；真实多模态感知、形成模型偏差、自然长期交互与跨模型泛化
须另行验证，不能从模拟 embedder 或固定提案推导。

## 实施与审查顺序

1. 先写可失败的纯算法测试和公开 SDK 回归测试。
2. 实现纯证明计算、SQLite 有界读取、显式策略和依赖刷新。
3. 跑 A/B 与 C/D 消融，保留所有失败、代价和否定结论。
4. 独立对抗审查证明非单调性、来源洗白、撤销、上限和评估泄漏；逐项复核并重测。
5. 跑仓库全部质量门禁，写研究结论和使用限制，不改变默认策略。

审查后的实现约束补充：祖先支持变化可能改变派生身份名称，必须同步投影到语音文本。
候选策略在同一 SQLite 事务提交前准备这些嵌入，失败则撤回整个变更；代价是事务可能
跨越嵌入调用。固定提案的图实验没有身份变化，仍要求各臂模型调用数相同。
